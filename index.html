How ordering works

See it. Request it. Confirm it.

This version uses an order request instead of automatic checkout, so you can confirm stock and the total before accepting payment.

  1. Choose a product from the website or Instagram.
  2. Submit the order request.
  3. You confirm stock, price, shipping/pickup, and payment.
  4. After payment, you pack and fulfill the order.
